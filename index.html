How to Convert HEIC to JPG on iPhone (Without Losing Quality)

If you've ever tried to send an iPhone photo to a Windows PC, upload it to an older website, or open it in an app that just refuses to load it, you've run into HEIC. Since iOS 11, iPhones save photos in HEIC (High Efficiency Image Container) by default instead of the older, more universal JPG format.

Why HEIC causes problems

HEIC compresses photos to roughly half the file size of an equivalent JPG at the same visual quality — great for saving storage on your phone, but it's a newer format that plenty of software, older Android phones, and some websites still don't recognize.

Three ways to convert HEIC to JPG

  1. Change it going forward: On iPhone, go to Settings → Camera → Formats → and select "Most Compatible." New photos will save as JPG automatically, but this won't touch photos you've already taken.
  2. Convert on export: When you AirDrop or email a HEIC photo to a non-Apple device, iOS usually converts it to JPG automatically. This doesn't work for every sharing method, though.
  3. Convert existing files directly: For photos already on your device or computer, run them through a converter that decodes HEIC and re-encodes it as JPG, preserving resolution and quality.

The third option is the most reliable when you need control over multiple files at once, or when you're not on an Apple device at all.

How to Convert Images to PDF for Free

Turning photos or scanned pages into a PDF is one of the most common file tasks there is — for job applications, forms, receipts, portfolios, or just archiving something so it can't be accidentally edited.

Why PDF instead of keeping images as-is

  • A PDF keeps multiple pages in one file, in a fixed order — no more attaching a dozen separate JPGs to an email.
  • It renders identically on every device, unlike images which can appear rotated or resized depending on the app.
  • You can add password protection, which most image formats don't support at all.

Getting a clean result

A few things make a noticeably better output:

  1. Upload images in the order you want them to appear — most tools stack pages in upload order.
  2. If you're scanning documents with your phone, shoot in good lighting and keep the page as flat and centered in frame as possible.
  3. Name the document clearly before generating it — it saves you a rename later.

How to Remove a Password from a PDF Safely

Password-protected PDFs are useful right up until you forget the password on your own file, or need to share a document with a team where re-typing a password every time gets old. Removing that protection is straightforward — as long as it's your own file, or one you have permission to modify.

Before you unlock anything

Only remove passwords from PDFs you created or have explicit rights to edit. Bypassing protection on someone else's document without permission isn't something any legitimate tool — including ours — is meant to help with.

What actually happens during unlocking

A PDF password unlocker reads the encrypted file, decrypts it using the password you provide, and re-saves a copy without that encryption layer. The content itself — text, images, layout — is untouched; only the lock is removed.

Why doing it in-browser matters

Some online "PDF unlocker" sites upload your file to a server to process it — which means a copy of a potentially sensitive document now lives somewhere you don't control. A tool that runs entirely client-side never sends your file anywhere; the decryption happens locally in your browser tab.

How to Merge Multiple PDFs Into One File

Whether it's combining scanned receipts for an expense report, stitching together chapters of a document, or assembling a set of invoices for a client, merging PDFs is one of those tasks that comes up constantly and shouldn't require installing any software.

The one thing that trips people up: order

Merge tools combine files in the order you upload or select them — not alphabetically, not by date. If the final document needs to read in a specific sequence, upload the files in that exact order, or rename them with a leading number (01, 02, 03...) beforehand so you can select them correctly.

What merging preserves

A proper PDF merge keeps every page's original text, images, and formatting exactly as-is — it's not re-rendering the pages as flat images, so text stays selectable and searchable, and file size doesn't balloon.

JPG vs PNG vs WEBP vs HEIC: Which Image Format Should You Use?

Every image format is a different trade-off between file size, quality, and compatibility. Here's the short version of when to reach for each one.

JPG — the universal default

Best for photos. Uses lossy compression, meaning it throws away some detail to shrink the file — usually imperceptible at normal quality settings. Opens absolutely everywhere. Not great for text, logos, or anything with sharp edges, since compression artifacts show up as blurring around hard lines.

PNG — when you need transparency or crisp edges

Lossless, so no quality is lost, but files are noticeably larger than JPG. The right choice for screenshots, logos, graphics with text, or any image that needs a transparent background.

WEBP — the modern all-rounder

Typically produces 25–35% smaller files than JPG at equivalent quality, and supports transparency like PNG. Nearly all modern browsers support it now, making it a strong default for web use — though some older software still doesn't open it.

HEIC — great on Apple devices, painful everywhere else

Apple's default photo format since 2017. Excellent compression, but poor compatibility outside the Apple ecosystem — worth converting to JPG before sharing broadly (see the HEIC to JPG guide above).

Quick decision guide

  • Sharing a photo with anyone, anywhere → JPG
  • Need a transparent background or crisp text/logo → PNG
  • Building a website and want smaller, fast-loading images → WEBP
  • Taking photos on an iPhone → they'll save as HEIC; convert before sharing outside Apple devices

How OCR Works: Turning Images and Scanned PDFs into Editable Text

OCR (Optical Character Recognition) is the technology that reads text inside an image — a scanned page, a photo of a receipt, a screenshot — and turns it into actual, selectable, editable text you can copy, search, or paste elsewhere.

What it's actually doing

OCR software analyzes the shapes in an image pixel by pixel, identifies patterns that match known letterforms, and reconstructs them as text characters — essentially teaching a computer to "read" the way a person would glance at a page.

Common everyday uses

  • Digitizing a scanned or printed document so it can be edited or searched
  • Pulling numbers off a receipt for expense tracking
  • Extracting text from a screenshot instead of retyping it
  • Making old, image-only PDFs searchable

Getting the most accurate results

  1. Good lighting, no glare — shadows and reflections are the most common cause of misread characters.
  2. Keep the page flat and straight-on — an angled or curved shot distorts letterforms.
  3. Higher resolution helps — a crisp, in-focus image gives OCR far more detail to work with than a blurry, low-res one.
  4. Plain backgrounds work best — busy or textured backgrounds behind the text can confuse the recognition.

Modern OCR handles printed text very reliably. Handwriting is a different, harder problem — results vary a lot depending on how neat and consistent the handwriting is.
